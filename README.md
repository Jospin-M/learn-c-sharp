# Learn C#

I created this repository to learn C# by writing and running small console programs. The exercises come from Codecademy and give me a place to practice each concept in code.

## Learning roadmap

These are the Codecademy topics this repository will cover as I work through the exercises.

### Fundamentals

- Setting up the C# development environment
- Inheritance
- Polymorphism
- Interfaces
- Reference fundamentals
- The `object` class
- String, The Exception

### Types, collections, and queries

- Enumerations
- Generics
- Collections
- Exceptions
- Nullable types
- Advanced methods and lambdas
- LINQ

### Beyond the fundamentals

- Delegates
- Events
- Asynchronous programming
- File I/O
- Iterators
